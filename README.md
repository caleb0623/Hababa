# Hababa Online Shopping

A static online shopping website built with HTML, CSS and JavaScript for a university web development assignment in 2021.

## Features

- Product pages by category: digital, fashion, food, furniture and household
- Shopping cart with add, remove and quantity controls, kept in `sessionStorage`
- Cart totals with a RM 3.50 shipping charge
- Sample payment form with field validation
- Sample register and login, kept in `localStorage`
- About, contact, FAQ and terms pages

This is a front-end demo. There is no backend, and no real accounts or payments.

## Tech

HTML, CSS, JavaScript, jQuery, Bootstrap 4

## Run

Open `index.html` in a browser.
